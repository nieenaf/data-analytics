Careers & Professional Development

Explore career pathways related to Data Analytics.

Career Opportunities

Data related skills can be applied across different roles and industries.

Data Analyst

Analyses datasets, creates reports and communicates findings to help organisations understand information.

Useful skills

  • Data analysis
  • Spreadsheets
  • Data visualisation
  • Communication

Business Analyst

Examines business needs and information to help organisations understand problems and identify possible improvements.

Useful skills

  • Problem solving
  • Business understanding
  • Requirements analysis
  • Communication

Data Scientist

Works with data using analytical and computational techniques to investigate complex questions and develop data driven solutions.

Useful skills

  • Statistics
  • Programming
  • Data analysis
  • Machine learning foundations

Professional Certifications and Learning Pathways

Certification / Pathway Focus How It Can Help
Microsoft Certified: Power BI Data Analyst Associate Data preparation, modelling, visualisation and Power BI. Can support development of practical business intelligence and data visualisation skills.
Google Data Analytics Professional Certificate Foundational data analytics concepts and workflows. Provides a structured learning pathway for beginners.
IBM Data Analytics Certificate Data analysis, spreadsheets, SQL and visualisation. Can help learners build a broad foundation in data analytics.

Building a Career

  1. Learn fundamental data concepts.
  2. Develop spreadsheet and visualisation skills.
  3. Learn database and SQL fundametals.
  4. Create small data projects for a portfolio.
  5. Explore relevant certifications and further study.
